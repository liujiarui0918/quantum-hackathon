# Quantum Hackathon

Code and presentation materials for the quantum hackathon project.

## Files

- `quantum_hackathon_page.html`: entry page for the web demo
- `quantum_hackathon_index.css`: styles for the web demo
- `quantum_hackathon_index.js`: bundled web demo script
- `quantum_hackathon_quantum_index.js`: quantum-related project script
- `quantum_hackathon_team_plan.tex` / `.pdf`: team plan slides
- `quantum_hackathon_topic_analysis.tex` / `.pdf`: topic analysis slides
