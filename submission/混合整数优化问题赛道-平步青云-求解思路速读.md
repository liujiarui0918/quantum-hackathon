# 混合整数优化问题赛道求解思路速读

队伍：平步青云  
当前提交主线：MIQP-aware Route 7

## 一句话思路

这题真实目标是最大化：

```text
maximize x^T Q x + c^T x + h^T y
subject to A x + G y <= b
           B x <= b'
           x in {0,1}^n, y >= 0
```

不要把连续变量 `y` 离散化塞进大 QUBO。正确主线是：让量子/退火/学习引导方法搜索二进制 `x` 的高价值 block，固定 `x` 后用 LP 精确求 `y`。

## Pipeline

```text
official .npz
  -> MiqpInstance
  -> binary variable scoring
  -> block selector, <=20 bits by default
  -> warm-start probabilities
  -> variable ranking / fixing plan
  -> block QUBO
  -> exact / annealing / learning-guided / QAOA-compatible backend
  -> candidate x
  -> solve continuous LP for y
  -> feasible objective and Benders-style cut advice
  -> next block
```

## 为什么这样做

- `x` 是组合爆炸来源，适合量子优化或量子启发搜索。
- `y` 在固定 `x` 后是线性规划，经典 LP 求解器更精确。
- 全量 QUBO 会因为连续变量离散化和约束 penalty 变得很大，很容易超过可模拟或可运行的 qubit 规模。
- block QUBO 可以稳定控制在 20 到 30 qubit 内，更符合当前 QAOA/Aer/退火的实际资源边界。

## 新增横向对比和图

`submission/baseline_study/` 里有一套更像论文实验的横向 study：

- `miqp_baseline_study.csv`：所有 baseline 数值。
- `miqp_baseline_study.md`：可读表格。
- `figures/`：目标值、gap、资源画像、block 热力图、warm-start 概率和流程图。

关键结论：样例 B 上，简单贪心 gap 约 10.78%，block-QAOA 单步候选 gap 约 20.02%，而 MIQP-aware route7 gap 约 5.32%。这说明优势主要来自 MIQP-aware 的 block + LP + cut 组合，而不是单独堆一个量子线路。

## 后续最值得优化的地方

1. 把 block selector 从启发式升级为 learned selector。
2. 用 exact / annealing / hybrid solver 给模拟图数据打标签，训练 `graph -> bit probability` 模型。
3. 把 cut advice 反馈到下一轮 block 选择，而不是只写入诊断。
4. 对 B 类大实例做多 seed、多 block destroy/repair、局部分支搜索。
5. 若有真实量子 backend 或 Aer GPU 时间，把 QAOA 只跑在小 block 上，不跑全量大 QUBO。
