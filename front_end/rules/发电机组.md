# 发电机组组合量子计算最优解
## 任务管理页面

任务管理页面包含标题区域和列表区域两部分

### 标题区域
单行展示，左侧：任务管理；在通栏最右侧有：“创建任务”的按钮
- 交互：点击“创建任务”弹出创建任务弹框

#### 创建任务
展示在一个弹窗中
表单项：
    - 任务名称：（name） 输入框 string
    - 基础设置：
        - 机组数量：（counts）输入框 number； 
        - 调度时段：（period）下拉框 string（备选项：24小时/48小时）
    - 系统约束：
        - 目标负荷需求：（targetNeed）输入框 number（单位：MW）
        - 备用容量上限：（backNeed）输入框 number（单位：MW）
        - 碳排放限额：（co2Limit）输入框 number（单位：吨/天）
    - 单机组约束：
        - 最小输出：（minOutput）滑块（区间：10-99 MW）；
        - 最大输出：（minOutput）滑块（区间：100-600 MW）；
        - 爬坡限制：（changeOimit）滑块（区间：5-20 MW/min）；
        - 启停时间：（startAndEndTime）下拉框（备选项：15分钟、30分钟、60分钟）；
        - 碳排放量：（co2Counts）滑块（区间：0.6-1.2 吨CO2/MWh）；
        - 启动成本：（startCosts）滑块（区间：2000 - 10000 元）；
        - 启动成本：（EndCosts）滑块（区间：500 - 2000 元）；
        - 燃料成本：（fuelCosts）滑块（区间：200 - 600 元/MWh）；
    - （交互：底部操作栏）
        - 取消：清空表单，弹窗消失
        - 确定：提交数据，清空表单，弹窗消失


### 任务列表
列表项：
    - 任务名称（name）
    - 基础设置：
        - 机组数量：（counts）
        - 调度时段：（period）
    - 系统约束：
        - 目标负荷需求：（targetNeed）
        - 备用容量上限：（backNeed）
        - 碳排放限额：（co2Limit）
    - 单机组约束：
        - 最小输出：（minOutput）
        - 最大输出：（minOutput）
        - 爬坡限制：（changeOimit）
        - 启停时间：（startAndEndTime）
        - 碳排放量：（co2Counts）
        - 启动成本：（startCosts）
        - 启动成本：（EndCosts）
        - 燃料成本：（fuelCosts）
    - 状态：
        - 未执行/执行中/已完成
    - 操作：
        - 编辑
            - 限制：只有“未执行”状态的任务能编辑，其他状态按钮不展示
            - 交互：点击后，出现“编辑任务”弹窗和“创建任务”一样，只不过有信息
        - 终止
            - 限制：只有“执行中”的任务才展示终止按钮
            - 交互：点击后，出现“确认终止”弹窗
                - 内容：确定要终止“${任务名}”的任务么？
                - （交互：底部操作栏）
                    - 取消：清空表单，弹窗消失
                    - 确定：调用终止接口，2s后刷新列表状态（终止成功后，任务状体置会为“未执行”）
        - 执行
            - 限制：只有“未执行”的任务才展示执行按钮
            - 交互：点击后，出现“确认执行”弹窗
                - 内容：确定要执行“${任务名}”的任务么？
                - 任务信息（不可编辑）：
                    - 任务名称：（name） 输入框 string
                    - 基础设置：
                        - 机组数量：（counts）输入框 number； 
                        - 调度时段：（period）下拉框 string（备选项：24小时/48小时）
                    - 系统约束：
                        - 目标负荷需求：（targetNeed）输入框 number（单位：MW）
                        - 备用容量上限：（backNeed）输入框 number（单位：MW）
                        - 碳排放限额：（co2Limit）输入框 number（单位：吨/天）
                    - 单机组约束：
                        - 最小输出：（minOutput）滑块（区间：10-99 MW）；
                        - 最大输出：（minOutput）滑块（区间：100-600 MW）；
                        - 爬坡限制：（changeOimit）滑块（区间：5-20 MW/min）；
                        - 启停时间：（startAndEndTime）下拉框（备选项：15分钟、30分钟、60分钟）；
                        - 碳排放量：（co2Counts）滑块（区间：0.6-1.2 吨CO2/MWh）；
                        - 启动成本：（startCosts）滑块（区间：2000 - 10000 元）；
                        - 关停成本：（EndCosts）滑块（区间：500 - 2000 元）；
                        - 燃料成本：（fuelCosts）滑块（区间：200 - 600 元/MWh）；
                - （交互：底部操作栏）
                    - 取消：清空表单，弹窗消失
                    - 确定：调用终止接口，2s后刷新列表状态（终止成功后，任务状体置会为“未执行”）
        - 查看结果
            - 限制：只有“执行完成”的任务才展示查看结果
            - 交互：点击后，跳转到“任务结果”页（新开页签）

## 任务结果页面
任务结果页纵向排列，分为（任务信息/约束校验 区域和结果展示区）：
    - 任务信息/约束校验（展示任务基础信息和约束信息）
        - 任务名称（name）
        - 基础设置：
            - 机组数量：（counts）
            - 调度时段：（period）
        - 系统约束：
            - 目标负荷需求：（targetNeed）（校验：通过/不通过，如果不通写明原因）
            - 备用容量上限：（backNeed）（校验：通过/不通过，如果不通写明原因）
            - 碳排放限额：（co2Limit）（校验：通过/不通过，如果不通写明原因）
        - 单机组约束：
            - 最小出力：（minOutput）（校验：通过/不通过，如果不通写明原因）
            - 最大出力：（minOutput）（校验：通过/不通过，如果不通写明原因）
            - 爬坡限制：（changeOimit）（校验：通过/不通过，如果不通写明原因）
            - 启停时间：（startAndEndTime）（校验：通过/不通过，如果不通写明原因）
            - 碳排放量：（co2Counts）（校验：通过/不通过，如果不通写明原因）
            - 启动成本：（startCosts）（校验：通过/不通过，如果不通写明原因）
            - 启动成本：（EndCosts）（校验：通过/不通过，如果不通写明原因）
            - 燃料成本：（fuelCosts）（校验：通过/不通过，如果不通写明原因）
        - （校验说明）
            - 通过，用绿色字体展示
            - 不通过，用红色字体展示，原因用黑色字体描述

    - 结果展示
        表格方式展示（但不展示表格的线）
        - 编号
        - 发电机组图片
            - 展示 imgs/power_egine.gif
        - 功耗
            - 发电量（单个发电机组的发电总量（MW））
            - 碳排放量（单个发电机组的碳排放总量（吨））
            - 总成本（${启动成本 + 关停成本 + 燃料成本}元）
            - 启动成本（单个发电机组的启动成本（元））
            - 关停成本（单个发电机组的关停成本（元））
            - 燃料成本（单个发电机组的燃料成本（元））
        - 功率时序图
            - 带辅助线的迷你折线图（用antV）（两个辅助线，一个是最小出力，一个是最大出力）
